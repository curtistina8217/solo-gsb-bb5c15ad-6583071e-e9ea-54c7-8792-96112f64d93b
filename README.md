# 圆筒包装接缝避让

输入筒体周长、接缝安全宽度与若干毫米制印刷保护区，系统按周长归一化跨零点区间、合并禁用旋转范围、列出全部可行角度段，并默认选择距禁用边界最远、角度最小的旋转量。Canvas 同步预览接缝与保护区，拖动时吸附到最近可行位置；无解时展示覆盖整圈的禁用区间链。

## 多规格共用角度模式

点击参数面板顶部的「多规格共用角度」切换：

- 输入 **2～8 个筒体周长**，沿用同一接缝安全宽度与同一组毫米制印刷保护区，系统对各规格分别计算，再把可行段统一到 **0°–360° 角度域** 求圆周交集，输出**所有规格均安全**的共用角度段；切回「单规格」时，原周长/接缝宽度/保护区等输入原样保留，不会丢失。
- 默认共用角度取**各规格下距禁用边界的最小间隙最大**的位置（即最宽共用可行段中点，间隙同时给出角度与各规格毫米值）；并列时取较小角度。
- 无共同解时，列出令交集**首次归零的规格**（序号 + 周长）及**冲突区间**：归零前共同可行段与该规格禁用段的逐对重叠。
- Canvas 外环为共用可行段（绿色；无共同解时以琥珀色高亮冲突区间），向内依次叠加各规格的禁用环（颜色与右侧列表对应，归零规格带标记），径向线为当前共用角度在各规格下的接缝位置；拖动圆盘吸附到最近的共用段端点。
- 右侧列表给出每段共用角度在各规格周长下对应的毫米范围，点击段可把其中点设为当前角度。

## 方案快照

- 在「方案快照」面板可为**当前周长、接缝宽度与保护区计算结果**命名并保存；快照按时间倒序列出，支持载入参数与删除。
- 勾选两个快照（依次标记为 A、B）后点击比较：系统将三类圆周区间（保护区、合并禁用段、可行段）统一归一化到 **0°–360°**，即使两个快照周长不同也可比较。
- 差异输出：
  - **新增**（B 有 A 无，绿色）／**移除**（A 有 B 无，红色）的圆周区间；
  - **边界移动**（紫色）：按重叠最大配对对应段，给出起点/终点沿最短圆弧的有向位移（顺时针 +、逆时针 −），跨零点自动取短弧；
  - 共有的部分以灰色底环显示。
- 差异 Canvas 上三个环分别对应可行段（外）、禁用段（中）、保护区（内），右栏列出逐段明细（角度，并附各快照周长下的毫米参考值）。
- 快照数据保存在浏览器 **localStorage**（键 `seam-avoidance:snapshots:v1`，最多 100 个），不经过服务器；清除浏览器数据即删除。重新计算或「返回实时预览」即回到原有实时预览。

http://localhost:3000

## API

| 方法与路径 | 说明 |
| ---------- | ---- |
| `POST /api/compute` | 单规格。请求体 `{circumference, seamWidth, zones:[{start,end}]}`，单位均为 mm |
| `POST /api/compute-multi` | 多规格共用角度。请求体 `{circumferences:[…2～8 个周长], seamWidth, zones}`；返回各规格角度域禁用/可行段、`commonSegments`（共用段）、`best.deg`（默认共用角度及各规格最小间隙 `best.perSpec`）；无共同解时 `noCommonSolution=true`，`culprit` 给出首次归零规格的序号 `index`、周长 `circumference` 与逐对 `conflictPairs`（含 `feasible`、`forbidden`、`overlap`，角度制） |
| `GET /api/health` | 健康检查 |
